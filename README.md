### Projects

#### [Aetylis](https://aetylis.com)

A tile fusion puzzle game, built from scratch: place tiles, trigger chain reactions, chase the high score. The game logic runs on a pure TypeScript engine, fully decoupled from React, so the rules don't know or care how they get rendered.

#### [Is This Band AI?](https://is-this-band-ia.vercel.app)

Is that artist you're listening to real, or an AI-generated project (Suno & co)? A verification pipeline cross-checks Spotify, MusicBrainz, Wikidata, and Setlist.fm before falling back to Gemini with web-grounded search for the ambiguous cases, keeping the cost per never-seen artist near zero once cached. React 19 + TypeScript on the frontend, Supabase (Postgres + Deno Edge Functions) on the backend.

#### [sophia-senhaji.com](https://sophia-senhaji.com)

My portfolio, built with Next.js and Tailwind CSS. Main contact and resume hub.

#### [steam-achievements-beta.vercel.app](https://steam-achievements-beta.vercel.app)

Steam achievements tracker. Uses Cloudflare browser rendering to scrape Steam guides and an LLM to parse the output into structured data.
